## Overview

Portfolio 2.0 is a React single-page site designed to present profile, software quality assurance, cloud security, and cybersecurity interests through a polished, interactive interface.

The application source is currently located in the `Faiyaz Portfolio 2.0/` subdirectory.

## Technology

| Area | Technology |
|---|---|
| App | React 18, Vite |
| Animation | Framer Motion |
| 3D effects | Three.js, React Three Fiber, Drei |
| Styling | Tailwind CSS, PostCSS |
| Icons | Lucide React |
| Hosting configuration | Netlify SPA routing via `netlify.toml` |

## Quick start

From the repository root:

```bash
cd "Faiyaz Portfolio 2.0"
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

The generated static site is written to `dist/`. For Netlify, use `Faiyaz Portfolio 2.0` as the base directory, `npm run build` as the build command, and `dist` as the publish directory.

## Main sections

- **Hero and About** — introduction, photo, education, and profile.
- **SQA** — software quality assurance skills and interests.
- **Cloud Security** — cloud security topics and experience.
- **Cybersecurity** — security profile, goals, and capabilities.
